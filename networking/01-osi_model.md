#  OSI models

---

It stands for Open System Interconnection model and was proposed by ISO
It enables communication between different systems irrespective of their architecture.
It works on layers architecture and has 7 layers in it

---

#  7 layers of OSI models

## 1 Application layer:
- It provides network services directly to applications.

### Protocols:
- HTTP
- HTTPS
- DNS
- Eg : web browsers

## Presentation layer
- It works as the translator 
- It makes sure that data is readable between systems 

### Functions 
- encryption  (secures data)
- compression (reduces data size)
- translation (converts data formats)

## Session layer
- responsible for establishing, maintaining and terminating sessions between systems 

### Functions
- starts session 
- maintains session 
- ends session 

## Transport layer
- It transports data from one system to another system 

### Protocols:
- TCP
- UDP

## Network layer
- It is responsible for routing packets between networks (similar to how internet send packets through network of routers )

## Data Link layer 
- Handles communication inside the same local network 
- Devices used in this layer are switches and access point 

## Physical layer 
- Deals with actual transmission of bits 
- Eg ethernet cables, fiber optics
