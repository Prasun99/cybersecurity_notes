# Basics for Cybersecurity – Networking

---

## 1. Computer Networks
A computer network is a telecommunication framework that allows digital devices (nodes) to communicate through wired or wireless means to share resources.

**Example:** Internet

---

## 2. Data Communication

### Components:
1. Sender  
2. Receiver  
3. Message  
4. Medium – Path through which the message travels  
5. Protocols – Rules governing communication  

---

## 3. Effectiveness of Data Communication

1. **Delivery** – Data should reach the correct destination  
2. **Accuracy** – Data should be error-free  
3. **Timeliness** – Data should arrive on time  
4. **Jitter** – Delay variation should be minimal  

---

## 4. Transmission Modes

### 1. Simplex
- One-way communication only  
- Example: Keyboard → Computer  

### 2. Half Duplex
- Two-way communication, but not at the same time  
- Example: Walkie-talkie  

### 3. Full Duplex
- Two-way communication simultaneously  
- Example: Phone call
