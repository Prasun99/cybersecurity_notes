# HTTP 
- HyperText Transfer Protocol
- HTTP is an application-layer protocol used for transferring web content between a client (browser) and server
- In HTTP, all information is sent without encryption between the device and server
- Default port: 80

# HTTPS 
- Secure HyperText Transfer Protocol
- It encrypts the data that is being retrieved by the HTTP
- To protect the data it uses two protocols
   - SSL
   - TLS
- Default port: 443
- Digital certifiates is used in HTTPS to verify website identity

## Importance
- prevents MITM (man-in-the-middle attacks)
- protects passwords and login data
- ensures website authenticity



## SSL
- Secure Socket Layer
- protocol that is used to ensure security on internet
- Uses public key encryption to secure data
- SSL is NOT used anymore in modern systems
- It has known vulnerabilities
## TLS
- Transport Layer Security
- Latest industry standard and is successor to SSL 
- Authenticates the client,server and encryptes the data
