# PortSwigger Web Security Academy Notes

This repository documents my learning journey through the **PortSwigger Web Security Academy** as part of my Application Security roadmap.

## Purpose

The goal of this repository is to:

* Build a strong understanding of common web application vulnerabilities.
* Learn how vulnerabilities occur rather than memorizing exploitation steps.
* Understand how developers can prevent these vulnerabilities.
* Practice using Burp Suite for security testing.
* Maintain organized notes for future revision and interview preparation.

> **Note:** These notes are educational and focus on understanding security concepts. They are not intended to be step-by-step exploitation guides.



---

## Learning Approach

For each lab I follow a consistent process:

1. Study the underlying theory.
2. Attempt the lab independently.
3. Analyze HTTP requests and responses using Burp Suite.
4. Identify the root cause of the vulnerability.
5. Understand its impact.
6. Document secure mitigations.
7. Record key lessons learned.
